## 一行で言うと

平安京全域（東西約4.5km×南北約5.2km）を均一に作るのではなく、北端中央の大内裏
（東西約1.16km×南北約1.39km、諸説あり）に絞り、朝堂院・大極殿を中心に精密化し、
周囲は段階的に精度を落とす。これにより「精密さ」と「全体の見通し」を両立させる。
