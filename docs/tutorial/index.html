Blender で平安京を描く — チュートリアル

このリポジトリのスクリプトで、平安京（大内裏の精密モデル＋市街の模式モデル）を Blender 上に生成し、静止画と動画にするまでの手順です。

1

環境構築

Blender 5.0 の導入、コマンドラインから呼ぶ設定、GPU の有効化。
2

スクリプト実行

配置CSVから大内裏 → 市街 → 動画カメラ → 連番レンダリングまでを順に実行。
3

GUIで静止画を作る

モデルを開いて視点を探し、カメラを置き、Cycles で高画質に書き出す。
4

GUIで動画を作る

カメラの動きを確かめ・直し、mp4 に書き出す。連番 PNG をビデオシーケンサーでまとめる。
5

カスタマイズ

配置・建物の形・色・光・市街の密度・カメラ経路を変える場所の早見表。

最短の流れ

Set-Alias blender "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe"
blender --background --python scripts/build_chodoin_detailed.py -- data/daidairi_layout_v3_1.csv output/heian_daidairi_detail_v7.blend output/view_v7 data/daidairi_conjectural_v1.csv
blender --background output/heian_daidairi_detail_v7.blend --python scripts/build_city_layer.py
blender --background output/heian_daidairi_detail_v7.blend --python scripts/setup_axis_animation.py
powershell -ExecutionPolicy Bypass -File scripts/render_axis_anim.ps1

できあがるもの（output/）：大内裏モデル v7、市街入りモデル v8、軸線動画用モデル、288枚の連番、確認画像。詳しくは 2章。

このモデルについて

  • 座標の原点は朱雀門の中心（X＝東、Y＝北、単位m）。基準年は 818年以降・9世紀前半。
  • 大内裏は配置CSVの根拠（史料確度 A〜C）に基づく。根拠のない部分を補った 推定レイヤー（確度D）と、町並み全体を確率で作った 市街レイヤー（模式）は、別コレクションに分けてある。
  • 根拠と経緯はリポジトリ直下の設計メモ（01_proposal.md〜10_city-layer.md）にまとめてある。

このチュートリアルの画面写真について

画面写真は Windows 11 上の Blender 5.0.0（日本語表示、UI倍率0.8）の実際の GUI です。撮影時は、画面切り替え・設定変更・クリック・レンダリングの実行を Blender 内部の操作（オペレーターと疑似マウス入力）で順に行い、Blender 内蔵のスクリーンショット機能で撮りました。手で同じ操作をすれば同じ画面になります。
