1. 環境構築

Blender本体とこのリポジトリを用意し、コマンドラインから Blender を呼べる状態にします。所要時間は10〜20分です。

動作確認した環境

項目確認した構成備考
OSWindows 11 PromacOS / Linux でもスクリプトは動きます（パスの書き方だけ読み替え）
Blender5.0.0（公式インストーラ版）4.2 LTS 以降なら概ね動く見込み。未検証
CPU / メモリ16スレッド / 32GB 推奨市街レイヤー（v8）は約1.5万オブジェクト。16GB でも動くが重い

手順1：Blender をインストールする

次のどちらかで入れます。

A. winget を使う（おすすめ）

PowerShell を開いて次を実行します。

winget install --id BlenderFoundation.Blender -e

B. 公式サイトのインストーラを使う

blender.org/download から Windows 版の .msi を取得して実行します。既定のインストール先は次の場所です。

C:\Program Files\Blender Foundation\Blender 5.0\blender.exe

手順2：コマンドラインから Blender を呼べるようにする

このプロジェクトのスクリプトは、blender --background --python ... の形で画面を出さずに実行します。毎回フルパスを書くのは長いので、PowerShell のエイリアスを作っておくと楽です。

Set-Alias blender "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe"

この設定は PowerShell を閉じると消えます。常に使いたい場合は、notepad $PROFILE で開いたファイルに同じ行を書き足してください。

確認：

blender --version

Blender 5.0.0 のように表示されれば完了です。

Git Bash を使う場合は alias blender="/c/Program Files/Blender Foundation/Blender 5.0/blender.exe" を ~/.bashrc に書きます。

手順3：リポジトリを取得する

git clone <このリポジトリのURL> yyBlenderHeian
cd yyBlenderHeian

中身は次の構成です。

場所内容
data/配置データ（CSV）。施設の位置・大きさ・史料の確度
scripts/Blender で動かす生成スクリプト（Python）と動画レンダリング用のシェルスクリプト
01_…〜10_….md提案書・設計メモ（なぜその形にしたかの根拠）
output/生成物（.blend と画像）。スクリプトを実行すると作られる。Git 管理外
docs/tutorial/このチュートリアル

手順4（任意）：GPU レンダリングを有効にする

コマンドラインで動かすスクリプトは、GPU を自動で探して使います（scripts/heian_gpu.py。見つからなければ CPU）。GUI で作業するときは、次の設定をしておくと GPU で描けます。

  1. Blender を起動し、メニューの Edit（編集）→ Preferences（プリファレンス） を開く。
  2. System（システム） の Cycles Render Devices で、NVIDIA なら OptiX（古い GPU は CUDA）、AMD なら HIP を選び、使う GPU にチェックを入れる。
  3. レンダー設定の Device を GPU Compute にする（3章で実際の画面を示します）。

手順5（任意）：FFmpeg を入れる

連番 PNG をコマンドラインで動画にしたい場合だけ必要です。

winget install --id Gyan.FFmpeg -e

Blender 5.0 で出る警告について：実行時に DeprecationWarning: 'Material.use_nodes' is expected to be removed in Blender 6.0 が出ますが、5.x では問題なく動きます。将来の Blender 6.0 ではスクリプトの修正が必要になります。
